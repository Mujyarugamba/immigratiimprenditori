## 1. Principi UX

- Chiaro, diretto, umano, professionale; inclusivo senza burocratese.
- Nessuna meta-spiegazione di database, RLS, aggregate, CTX/ACT, fasi P*.
- Distinzioni di prodotto preservate e spiegate in linguaggio naturale.
- Identità piattaforma e cinque ecosistemi invariati; Cultura e Osservatorio trasversali.

## 2. Aree revisionate

| Area | Esito |
|------|--------|
| Home + ecosistemi + CTA | Humanizzata; meta home via `label()` |
| Persone / professionisti / profilo pubblico | Linguaggio “profilo”, non entity |
| Imprese pubbliche + private | Collegate vs gestibili; status IT |
| Opportunità / collaborazioni | Distinzione senza jargon AR |
| Servizi | Offro / cerco |
| Mercati / eventi / organizzazioni | Label catalogo; Referenti |
| Cultura (hub completo) | Copy naturale; empty contestuali |
| Contenuti pubblici | Titolo “Notizie e guide” (route invariata) |
| Osservatorio | Tono informativo; meta periodo/unità |
| Auth / pubblica / not-found / forbidden | Azionabile, senza triad Auth/Account/Persona |
| Dashboard / sidebar / onboarding | Label umane |
| Redazione | Bozza / Pubblicato / Ritirato |
| Amministrazione | Operativo; UUID solo dove utile |
| AppError / empty / success / CTA | Remapping umano |

## 3. Tecnicismi rimossi (esempi)

| Before | After |
|--------|--------|
| aggrega fatti… classificazione strutturata | incontri, persone… già presenti nella rete |
| aggregate root distinti | percorsi separati / occasioni vs collaborazioni |
| workspace (CTX ≠ ACT) | area riservata; collegare ≠ gestire |
