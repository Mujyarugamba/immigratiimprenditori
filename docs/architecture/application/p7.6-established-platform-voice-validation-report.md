---

## 3. Empty state modificati (sintesi)

- Default `EmptyState` / `PublicEmpty`: titolo “Nessun risultato.”; descrizione opzionale.
- Home: una sola riga neutra per dominio (es. “Nessun professionista disponibile.”) — senza seconda riga futura.
- Directory: “Nessun … trovato.” + “Nessun … corrisponde ai filtri selezionati.” dove i filtri esistono.
- Cultura: titoli “Nessun … disponibile.” / “Nessun incontro culturale in programma.” senza promesse future.
- Osservatorio: “Nessun indicatore disponibile.” + messaggio filtri, non “quando saranno disponibili”.

## 5. Home / Cultura / Footer / Osservatorio / Auth

- **Home:** descrizioni al presente; empty neutri; CTA concreta; micro-copy mercati/eventi rivisti.
- **Cultura:** hub come percorso già nella rete; empty senza “quando saranno pubblicati…”.
- **Footer:** nessun disclaimer di popolamento progressivo.
- **Osservatorio:** empty = disponibilità/filtri; label IT invariate (P7.5); nessuna narrativa di immaturità.
- **Auth / private:** onboarding resta operativo (“Completa il profilo…”); conseguenza azione utente, non futuro della piattaforma.

---

## 6. “Quando” mantenuto legittimamente

- Label catalogo `future` → “Disponibile in futuro” (`labels.ts`) — status item, non voce piattaforma.
- Copy di conseguenza utente: “Completa il profilo…”, “Finché non è risolto…”.
- “Prossimi incontri” (Cultura) = eventi imminenti, non “sito in arrivo”.
- Documentazione architetturale interna (non UI) non rientra nello scope.

---

## 7. Conferme di invarianti

- Nessun contenuto, numero, testimonianza o card inventata.
- Semantica: Account ≠ Persona, CTX ≠ ACT, Opportunity ≠ Collaboration, Service Offer ≠ Request, Event ≠ Edition, Cultura trasversale, 5 ecosistemi — invariate.
- Authorization / RLS / grant / schema — invariati.
- Dirt preesistente escluso dallo stage: `.gitignore`, `application-v1-deployment-report.md`.
