## Signup

- Checkbox: “Accetto i Termini d’Uso” → `/termini` (not pre-checked).
- Privacy: separate informational link → `/privacy` (not consent).
- Server validation before `auth.signUp` (`parseTermsAcceptedFromForm`).
- After Account provision: insert ledger **without** `accepted_at`.
- Intent also stored in Auth `user_metadata.terms_of_use_accepted_version` for email-confirm / retry paths.
- Login + auth callback + onboarding complete the ledger when metadata intent matches current SoT (idempotent on unique).

## Failure semantics

Signup is multi-step (Auth → Account provision → ledger). Auth rollback is not available.

Fail-safe implemented:

1. Checkbox missing → reject **before** Auth signup.
2. Session path: if ledger INSERT fails (non-unique) → **signOut**, human error, no onboarding redirect.
3. Metadata retains acceptance intent → login / callback / onboarding retry write (unique = success).
4. Legacy accounts **without** metadata: no forced re-consent, no false backfill.

## Legacy accounts
