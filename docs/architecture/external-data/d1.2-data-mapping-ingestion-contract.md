| retrieved_at | gap → `consulted_at` proxy o sidecar; M2 later |
| last_source_update | sidecar / updated_at |

### Review workflow (no second CMS)

```
FETCH → NORMALIZE → DEDUPE → VALIDATE → PENDING REVIEW
  → editorial_status=in_review
  → EDITOR → approved + published / rejected
```

Defaults insert: `origin=external`, `editorial_status=draft|in_review`, `publication_status=unpublished`, `visibility_level=private`.
**Gap:** nessuno bloccante; dedup UNIQUE DB assente → convention + future M2.
