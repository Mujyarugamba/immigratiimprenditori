## 9. ISTAT

- Canale: IstatData + SDMX REST `https://esploradati.istat.it/SDMXWS/rest`
- Licenza: CC BY 4.0 (riuso dichiarato)
- Formati: SDMX-JSON/ML/CSV
- Rate limit noto ~5 req/min; attenzione bug `endPeriod`
- Temi: demografia stranieri, lavoro autonomo, imprese, territori
- Decisione: **PILOT canale** + dataset selected

---

## 10. Unioncamere

- OpenGov CSV/DCAT: **OPEN DATA RIUTILIZZABILE** (tip. CC-BY 4.0 per-dataset)
- Futurae / Osservatorio imprese straniere: dashboard + rapporti — **consultabili**; numeri da preferire via open data
- Definizione da preservare: partecipazione/controllo prevalente di persone fisiche **non nate in Italia** (non sinonimo di cittadinanza)
- Movimprese: dinamica RI; SEMI-AUTO
- InfoCamere: infrastruttura; non duplicare
- Decisione: **PILOT OpenGov**; Futurae = metodologia + editorial

---

## 11. Eurostat

- API dissemination ufficiali; dataset es. `lfsa_esgan`
- Utile per confronti UE (self-employment × citizenship, migration labour, business demography, culture stats selettive)
- Preferire ISTAT per serie Italia nazionali equivalenti
- Decisione: **PILOT** `lfsa_esgan` + shortlist

---

## 12. Incentivi.gov.it

- Open data page ufficiale; CSV+JSON; **IODL 2.0**
- Campi utili: misure, admin, territori, settori, aperture/chiusure, stato, URL
- Compatibilità alta con Opportunity + `opportunity_sources`
- Decisione: **PILOT** Wave D1-B

## 13. EU Funding & Tenders
