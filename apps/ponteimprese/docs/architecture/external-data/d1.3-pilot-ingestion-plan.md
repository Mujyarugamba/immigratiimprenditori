## 3. Allowlist fonti pilot

### 3.1 Eurostat

- URL pattern allowlist: `https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data/lfsa_esgan`
- Filters fissi pilot: `geo=IT`, `sex=T`, `age=Y15-64`, `wstatus=SELF`, `unit=THS_PER`, `citizen` ∈ {NAT, FOR, EU27_2020_FOR, NEU27_2020_FOR, TOTAL_POP/STLS se utile}
- Rate limit: rispettare policy Eurostat; backoff

### 3.2 Unioncamere OpenGov

- Host allowlist: `https://opengovernment.unioncamere.gov.it/`
- Dataset allowlist iniziale (esempi verificati tema imprese straniere / Lombardia-affine):
  - Cremona-Mantova-Pavia imprese straniere 2024 (`P51F520` e successori)
  - Altri CSV Lombardia con tema «Imprenditoria straniera» + CC BY 4.0, aggiunti solo via config review
- **Non** include elenchi nominativi imprese
- Milano MB Lodi: al 2026-08-11 non risulta dataset OpenGov dedicato «imprese straniere»; non forzare demografia generica come proxy

### 3.3 Futurae national (SEMI)

- Input: file curato versionato (es. `config/ingestion/futurae_national_stock.json`) compilato da editor da report ufficiale
- Ogni riga: year, stock, total?, source_url, edition, license/attribution
- Nessun PDF parsing automatico in D1.3

## 4. Importer architecture (D1.3 implementazione futura)

| Scelta | Decisione |
|---|---|
| Runtime | **Node.js scripts** offline nel repo (`scripts/ingestion/` o `tools/ingestion/`) |
| Non | browser, Edge Function prima scelta, CI schedule obbligatorio |
| Privilege | **service_role** solo server/local tooling (env non committata) oppure DB owner connection; mai client |
| Alternativa | editor JWT + `access_is_editor()` se si vuole audit utente |
| Config | allowlisted URLs + indicator codes + territory crosswalk YAML/JSON |
| Output | console + `artifacts/ingestion/<run_id>/manifest.json` |

Flusso:

```
load config → fetch allowlisted → normalize → validate → dedupe/checksum
→ dry-run report → (explicit --apply) upsert domain draft/published per policy
```

## 5. Dry-run contract

Output obbligatorio:

```
run_id
source
fetched
valid
new
updated
unchanged
rejected
review_required
errors[] (code, message, natural_key?)
```

Exit code ≠ 0 se `SOURCE_UNAVAILABLE` o errori hard > soglia.

## 6. Limits (da implementare in D1.3)

- max records per run (es. 500)
- timeout fetch (es. 30s)
- retry 3 con backoff
- pagination solo se API la richiede
- User-Agent: `ImmigratiImprenditori-Ingestion/0.1 (+contact)`
- max download size (es. 5 MB CSV)

## 7. Failure model

| Code | Retry | Quarantine | Manual |
|---|---|---|---|
| SOURCE_UNAVAILABLE | YES | — | if persistent |
| SOURCE_SCHEMA_CHANGED | NO | YES | YES |
| INVALID_PAYLOAD | NO | YES | — |
| UNMAPPABLE_TERRITORY | NO | YES | YES |
| UNMAPPABLE_DIMENSION | NO | YES | YES |
| DUPLICATE | — | — | log |
| LICENSE_BLOCKED | NO | YES | YES |
| VALIDATION_FAILED | NO | YES | — |
| REVIEW_REQUIRED | — | — | YES (Opportunity; rare for obs pilot) |

---

## 8. Missing source / withdrawn

| Caso | Comportamento Osservatorio |
|---|---|
| missing once | log; keep published |
| missing N runs (es. 3) | flag source `unavailable` candidate; **non** auto-delete values |
| value removed at source | non withdraw automatico; review |
| correction | SUPERSEDE |

Opportunity (futuro D1-B): deadline passed ≠ delete; `publication_status`/`time_windows` governano; missing source → `opportunity_sources.status=unreachable` dopo N run, scheda resta.

## 10. Security requirements D1.3

- Fetch solo URL allowlisted
- No redirect off-allowlist (SSRF)
- Cap size; reject zip bombs
- CSV formula injection: treat cells as data
- No secrets in logs
- Validate numeric parse
- PII gate: reject datasets with nomi/CF/email

---

## 11. Observability

Log: `run_id`, source, start/end, counts, error categories, source version, checksum/config version.
No tokens, no raw PII.

---

## 12. Copyright / privacy gates pre-apply

Per ogni source nel run:

- `license_verified=true` in config
- `pii_class=aggregate`
- `publication_permission` coerente con licensing contract
