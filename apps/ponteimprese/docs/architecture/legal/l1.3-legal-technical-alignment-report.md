## 5. Account deletion — pre-state & design

### Pre (A)

- Only admin `access_close_account` soft-closes `accounts` (`closed` + `closed_at`).
- Does **not** delete Auth, profiles, roles, memberships, grants.
- Self-service UI: **NOT FOUND**.

### Target solution (aligned to legal texts) — D / E until applied

1. Self-service “Cancella account” in area riservata (human copy, confirm, session invalidate).
2. Effects: stop auth/access; revoke personal roles/grants; soft-unpublish Persona; clear contact channels; **do not** delete autonomous Imprese/Organizzazioni/Opportunità/…
3. Minimized legal archive (separate) only when a concrete reason exists.
4. Orphan-manager entities: persist entity; clear authorization toward closed account; introduce explicit `needs_reassignment` (or equivalent) — **no auto-owner transfer**.

### Orphan entity proposal (D — no invent owner)

When sole ACT grant is revoked or account closes:

- Revoke/clear authorization toward that Account/Person.
- Set Impresa flag/status `management_needs_reassignment` (new axis or column — TBD in M4 physical note).
- Keep `publication_status` policy: prefer freeze ACT writes; do **not** auto-delete Impresa.
- Person-owned Organization: clear `owner_person_id` only via controlled admin transfer RPC later; until then block hard Person delete (already RESTRICT) and mark org needs reassignment.
- Admin queue to re-bootstrap grant / transfer ownership with explicit ACT.

**No automatic transfer to another user.**
